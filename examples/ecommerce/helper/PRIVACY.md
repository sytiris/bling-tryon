# Data and privacy

- **Permanent API key:** entered on your local setup page and persisted only in your local configuration directory. Sent to `https://api.decart.ai` (Decart) or the selected `https://api.vidu.cn` / `https://api.vidu.com` region (Vidu) to verify/request session credentials, never to the author. Decart and Vidu keys are kept separately in `user.env` and `vidu.env`. The extension does not store them.
- **Temporary tokens:** obtained when needed, restricted by model, expiry and session duration for Decart. Vidu supplies scoped RTC join credentials; the local helper proxies control signaling using an opaque per-session capability and keeps the upstream control secret private. Not persisted across sessions.
- **Camera:** enabled with your permission, for local preview first. After you click 10/20 sec, a center-square video feed is sent to your selected provider over WebRTC (Vidu uses Aliyun RTC). Audio is always off.
- **Clothing:** the selected image URL is held temporarily. Starting a try-on downloads, compresses and sends the image to your selected provider. The image host can observe the download request.
- **Replay video:** a silent center-square recording of the AI output is held in browser memory for the current trial. It is not sent back to a provider or the author. Normal completion plays it once. Closing replay, a new trial, camera off, minimizing/closing, hiding or refreshing clears it. Files are saved only when you explicitly click Download; downloaded files remain on your computer until you delete them.
- **Last frame:** kept only in the current mirror's local canvas; not automatically saved to disk or sent to the author.
- **Local helper:** listens on 127.0.0.1. Management endpoints check local Origin and a per-process random CSRF token. No author account service, ads or author analytics. Decart SDK telemetry is disabled. Vidu uses a locally bundled Aliyun RTC SDK; its logging is silenced and optional diagnostic wrapping is disabled, but necessary provider/transport service diagnostics may still be sent. This is not a promise of zero third-party telemetry. Vidu control WebSockets require the extension Origin and a one-use session attachment; heartbeat expiry, explicit hangup and local deadlines limit abandoned sessions.
- **Language:** the extension stores only a language preference in Chrome local storage, and the helper in browser localStorage. Keys are never stored there. Neither preference is synced to the author's service.
- **Third parties:** The selected model provider's privacy policy, processing terms and account settings apply; Vidu also uses Aliyun RTC. This project does not promise zero third-party retention.
- **Deletion:** delete the locally saved key from setup. Any separate development `.env.local` backups or system environment values must be removed yourself. Select each provider in setup to delete its local key; provider/region preferences contain no key. Revoke the platform key in its own console.
