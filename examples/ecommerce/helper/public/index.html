第一次使用？先注册 / 登录 Decart，在控制台查看试用积分，再创建 API Key。新账户试用额度和有效期以平台显示为准；本工具不会自动充值。

准备好之后，打开试衣镜

  1. 打开 ，开启「开发者模式」。
  2. 点击「加载未打包的扩展程序」，选择安装包里的 chrome-tryon 文件夹。
  3. 回到购物网页，点插件图标。选一件衣服，允许摄像头，再点 10 秒 / 20 秒。

保持助手终端开启。关闭此网页不会停止助手；终端按 Ctrl+C 退出。

开始试穿才连接 AI；到点自动断开。10/20 秒从出画起算，实际生成计费可能更长。正方形取景不降低每秒费用。

密钥只保存在本机配置目录，不会发送给插件作者。相机画面和服装图片仅在你点击试穿后发送给 Decart。本工具与 Decart 官方无隶属关系。
