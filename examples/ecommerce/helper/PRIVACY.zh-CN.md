# 数据与隐私

- 永久 API Key：由用户在本机配置页填写，仅持久化到用户本机配置目录。验证和申请会话凭证时发送至 Decart 的 `https://api.decart.ai`，或所选 Vidu 地区的 `https://api.vidu.cn` / `https://api.vidu.com`；不发送给项目作者。两家密钥分别保存在 `user.env` / `vidu.env`；插件不保存永久 Key。
- 短期令牌：插件点击试穿后按需取得，Decart 限制模型、有效期和会话时长；Vidu 提供临时 RTC 入会凭证，本地助手通过不透明的会话控制凭证代理控制信令，上游控制密钥留在助手；不做跨会话持久化。
- 相机画面：仅在用户同意后开启。试穿前为本机预览；主动点击10/20秒后，中心正方形画面经WebRTC发送给所选平台处理（Vidu 通过阿里云 RTC 传输）。音频始终关闭。
- 服装图片：仅在用户点选时暂存来源URL，点击试穿后下载、压缩并发送给所选平台。网页图片主机可获知图片读取请求。
- 回放视频：本次AI输出的中心正方形画面以无声视频暂存在浏览器内存，不再次发给模型平台或作者。正常结束自动播放一次；关闭回放、开始下一次试穿、关闭摄像头、收起/关闭、隐藏/刷新页面时清除。只有主动点击下载才保存文件，已下载文件需用户自行删除。
- 最后一帧：仅保留在当前浮窗的本地画布内，不自动保存文件或上传给作者。
- 本地助手：仅监听127.0.0.1，管理接口检查本机Origin及进程随机CSRF令牌。没有用户账号服务、广告或作者分析。Decart SDK 遥测关闭；Vidu 使用本地打包的阿里云 RTC SDK，关闭其控制台日志及可选诊断包装，但必要的模型/传输服务诊断仍可能发送，不承诺第三方零遥测。Vidu 控制 WebSocket 检查扩展 Origin 和一次性会话绑定，并通过心跳超时、主动挂断和本地时限限制遗留会话。
- 语言：插件在 Chrome 本地存储、助手在浏览器 localStorage 中各自只保存语言偏好，不在其中保存密钥，也不向作者同步。
- 第三方：所选模型平台的隐私政策、数据处理条款与账户设置仍适用，Vidu 另使用阿里云 RTC；本工具不承诺第三方默认零留存。
- 删除：助手设置页可删除本机保存的Key。源代码调试时如另有.env.local备份或系统环境变量，需用户自行清理；请在助手选择各平台分别删除其本地密钥，平台/地区偏好不含密钥；撤销平台密钥请前往对应控制台。
